# Mobile app (starter)

This folder contains starter files for the React Native (Expo) mobile app.

How to create/run locally:

1. Create the Expo project (recommended to run locally):

```powershell
npx create-expo-app mobile-app --template expo-template-blank-typescript
cd mobile-app
npm install
npx expo start
```

2. Alternatively, use these starter files as a reference to scaffold screens and navigation.

Files in this folder are templates and not a fully-initialized Expo project. Run the `create-expo-app` command above to generate the proper project structure.
